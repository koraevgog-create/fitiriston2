# IRISTON — публичный сайт фитнес-тренера

Статический сайт, без сборки и внешних зависимостей. GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

- index.html — контент и SEO
- assets/style.css — адаптивный дизайн
- assets/app.js — меню, выбор цели, подготовка сообщения
- assets/config.js — будущие контакты
- assets/images/ — фотографии в WebP

Контакты, цены, отзывы и результаты нужно заполнить реальными данными. Форма до подключения контактов только подготавливает сообщение, не отправляет заявку. Перед публичным запуском подтвердить форматы услуг и разрешение на публикацию фотографий.
